
# Excel 自动分析助手

## 一、项目简介

使用 Python 和 Pandas 开发的 Excel 数据自动分析工具。

可以读取学生成绩 Excel 文件，完成数据清洗、成绩统计、排名和图表生成。

## 二、使用技术

- Python
- Pandas
- Matplotlib
- Openpyxl

## 三、主要功能

1. 读取 Excel 文件
2. 删除重复数据
3. 处理缺失值
4. 计算学生总分和平均分
5. 按班级统计成绩
6. 统计各科最高分、最低分和平均分
7. 自动生成成绩排名
8. 自动生成统计图表

## 四、运行方法

安装依赖：

```bash
python -m pip install pandas openpyxl matplotlib
```

运行程序：

```bash
python analysis.py
```

## 五、项目输出

分析结果保存在 output 文件夹中。

## 六、项目收获

通过本项目学习了 Python 文件操作、Pandas 数据处理、
Excel 自动化分析和 Matplotlib 数据可视化。
